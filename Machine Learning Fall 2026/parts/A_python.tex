\section{Setting Up}

Install the Anaconda distribution (Python 3.10 or later); it includes NumPy, pandas,
SciPy, Matplotlib, scikit-learn and Jupyter. Check the installation with:
\begin{lstlisting}[language=Python]
import numpy, pandas, scipy, sklearn
print(numpy.__version__, pandas.__version__, sklearn.__version__)
\end{lstlisting}
The labs were tested with NumPy 2.3 and scikit-learn 1.7. Run a lab file from a
terminal with \texttt{python ch05\_least\_squares\_three\_ways.py}, or paste it into a
notebook cell.

\section{The scikit-learn Pattern}

Every lab follows the same shape. Learn it once:
\begin{lstlisting}[language=Python]
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

X_tr, X_te, y_tr, y_te = train_test_split(       # 1. split first
    X, y, test_size=0.25, stratify=y, random_state=0)
model = make_pipeline(StandardScaler(),           # 2. prepare + model
                      LogisticRegression(max_iter=1000))
scores = cross_val_score(model, X_tr, y_tr, cv=5)  # 3. compare by CV
model.fit(X_tr, y_tr)                             # 4. fit on training
print(scores.mean(), model.score(X_te, y_te))     # 5. test once
\end{lstlisting}

\section{Errors Students Meet Every Semester}

\rowcolors{2}{white}{lightbg}
\begin{longtable}{@{}L{5.4cm}L{9.6cm}@{}}
\toprule
\rowcolor{primary!15}
\textbf{Message} & \textbf{Usual cause and fix} \\
\midrule
\endhead
\texttt{ConvergenceWarning} & The optimiser stopped early: scale the features, or raise \texttt{max\_iter} \\
\texttt{could not convert string to float} & A categorical column reached the model: one-hot encode it \\
\texttt{Input contains NaN} & Missing values: add \texttt{SimpleImputer} to the pipeline \\
\texttt{Expected 2D array, got 1D} & One example or one feature: use \texttt{x.reshape(1, -1)} or \texttt{X[:, [j]]} \\
Accuracy suspiciously high & Leakage (\chref{workflow}) or an imbalanced baseline (\chref{evaluation}) \\
Different results every run & No \texttt{random\_state}: fix the seeds \\
\bottomrule
\end{longtable}
