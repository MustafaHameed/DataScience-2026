What each of the three fields proves (checkpoint question 2):
  Measurement  -- WHAT is running. Compare with the expected file. If it
                  differs, a different image booted: do not release the key.
  Report Data  -- that the report is FRESH. It echoes the nonce you sent,
                  so it cannot be a recording of an earlier genuine boot.
  Signature    -- that the report came from GENUINE AMD hardware, chaining
                  through the VCEK and ASK to the AMD root key.

  Skip the comparison and all of this is decoration: an operator who boots
  a modified image gets a perfectly valid, perfectly signed report with a
  DIFFERENT measurement, and its memory is beautifully encrypted while it
  sends your data somewhere else.
